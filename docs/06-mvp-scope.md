# 06. MVP 범위

| 구분 | 항목 | 비고 |
|---|---|---|
| **포함** | A 신청 관리, B Validation 엔진, C Error Code + Global Exception Handler, D 결재↔LegacyProv 자동 비교 (+ 가상 LegacyProv), E 연장 분기, G-lite 개통 직후 결과 검증 | G-lite: D의 비교 로직 재사용 |
| **후순위** | H 알려진 오류 자동 롤백, I 대량 연장 Batch, J RAG 업무 도우미 | 핵심 안정 후 |
| **Non-Goal** | 전자결재 구현, LegacyProv 재개발, 화려한 UI, 규칙 관리 화면, 정책의 몰래 강화 | 범위 방어 |

## 현실 제약과 점진 전달
주 14시간, 약 15주 (추정치 약 210h, 버퍼 20% 포함). 문서 작업을 포함한다.

| 버전 | 포함 | 누적 | 시연 가능 장면 |
|---|---|---|---|
| v0.1 | 셋업 + A + B + C | 약 5주 | 오류 3개를 한 번에 반환 |
| v0.2 | + D + G-lite | 약 9주 | 결재↔LegacyProv 불일치를 코드로 반환 |
| v0.3 | + E + 문서 마무리 | 약 15주 | 연장 분기 전체 |

각 버전은 단독으로도 포트폴리오가 성립해야 한다.

## 데모 시나리오 (3분)
1. 잘못된 신규 신청 → 오류 3개를 코드와 해결 방법과 함께 한 번에 반환 → 수정하면 통과
2. 승인 완료 후 자동 비교에서 `DEVICE_NUMBER_MISMATCH` 반환
3. 번호 유지 연장을 통보서 없이 신청 → `REQUIRED_DOCUMENT_MISSING`으로 차단
4. (추가) 가상 LegacyProv가 잘못된 요금제를 통과시켜도 개통 직후 검증이 잡아냄
