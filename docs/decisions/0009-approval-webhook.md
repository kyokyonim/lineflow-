# ADR-0009. 결재 결과는 웹훅으로 수신

- **상태**: 확정 (보완 필요)
- **결정**: ApprovalHub가 승인 결과를 LineFlow의 API를 호출하여 알려준다 (웹훅). 가상 ApprovalHub가 호출하는 것으로 정의한다.
- **대안**: LineFlow가 주기적으로 ApprovalHub에 승인 여부를 조회 (폴링) → 단순하고 상대 협조가 불필요하지만 지연과 불필요한 호출이 생긴다.
- **알려진 약점**: 서버 장애 시 알림 누락, 같은 알림의 중복 수신, 순서 뒤바뀜, 위조 호출.
- **보완 과제 (STEP 15)**: 멱등 처리(같은 승인 알림이 두 번 와도 결과 동일), 보조 폴링으로 누락 복구, 호출자 인증.
- **현실 고려**: 실제로는 상대 시스템의 웹훅 지원 여부가 방식을 결정한다.
