# ADR-0005. 번호는 PK가 아니고, 번호 변경은 새 Line + 이전 Line 링크

- **상태**: 확정
- **결정**: 번호(phone number)는 식별자(PK)로 쓰지 않는다. 연장으로 번호가 바뀌면 새 번호가 배정된 새 Line을 만들고, 새 Line이 이전 Line을 가리킨다.
- **배경**: 번호는 바뀌거나 종료 후 재사용될 수 있다. 번호 자원은 LegacyProv가 배정하며, 번호가 바뀌면 새 회선이 배정되는 구조다.
- **대안**: 시험 단위로 Line을 두고 번호 이력만 쌓기 → 이력 조회는 쉽지만 LegacyProv와 구조가 달라 대응이 복잡하다. MVP는 외부 시스템을 거울처럼 따르는 쪽이 단순하다.
- **결과**: 번호 중복 방지는 "활성 회선 중에서만 유니크"로 표현한다.
