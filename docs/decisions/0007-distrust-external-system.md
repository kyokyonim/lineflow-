# ADR-0007. 외부 시스템 결과는 사후 검증한다

- **상태**: 확정
- **결정**: LegacyProv의 검증과 결과를 신뢰하지 않는다. 신청 시점, 개통 직전, 개통 직후 세 지점에서 우리가 검증한다. LegacyProv의 에러는 Anti-Corruption Layer에서 우리 도메인 언어로 번역한다.
- **배경**: (가상 일반화) LegacyProv가 잘못된 요금제를 통과시키는 경우가 있고, 번호 풀이 잘못 배정된 사고가 있었다. 에러 메시지는 하위 오류를 뭉뚱그린다.
- **번역 예**: "변경 없음" 에러는 실패가 아니라 SKIPPED(변경 불필요)로 처리한다.
- **검증 대상**: 개통 직후 배정된 번호 풀과 요금제가 단말 유형과 일치하는가.
- **테스트 전략**: 가상 LegacyProv에 결함을 일부러 주입(Fault Injection)하여 우리 시스템이 잡아내는지 확인한다.
- **결과**: 대량 신청은 소량 먼저 개통해 검증 후 진행하는 방식을 후순위(Batch)에서 검토한다 (피해 범위 제한).
