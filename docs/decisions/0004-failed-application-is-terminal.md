# ADR-0004. 실패한 신청은 종료 상태, 재신청은 새 신청

- **상태**: 확정
- **결정**: 실패한 신청은 `COMPARE_FAILED` / `ROLLED_BACK` 같은 종료 상태로 남기고, 재신청은 새 Application으로 만든다. 레코드는 삭제하지 않는다.
- **배경**: 어떤 오류가 어느 단계에서 몇 번 났는지 남아야 문제 추적과 개선 우선순위 판단이 가능하다. (현재는 엑셀 비고 자유 텍스트라 집계 불가)
- **대안**: 상태를 신청 단계로 되돌림 → 지금 어디까지 했는지, 과거에 무엇이 실패했는지 추적이 어렵다.
- **관련**: 상태 변경 이력 테이블과 오류 이력 테이블에 누적한다. 사전 검증에서 막은 오류도 기록해 자동화의 가치를 숫자로 증명한다.
- **참고**: 레코드를 남긴다고 영구 보존은 아니다. 보존 기간 정책은 비기능 요구사항에서 정의한다.
