# ADR-0003. 신청 오류는 전체 반려

- **상태**: 확정
- **결정**: 한 신청의 항목 중 일부가 오류여도 신청 전체를 반려하고 수정 후 재제출하게 한다.
- **배경**: 전자결재 승인은 항목 하나하나가 아니라 신청 전체(예: 100건 묶음)에 대해 난다.
- **대안**: 정상 항목만 부분 접수 → 승인된 건수와 접수된 건수가 어긋난다.
- **근거 개념**: 원자성(Atomicity). 전부 성공하거나 전부 실패해야 한다.
- **결과**: 반려 응답에 모든 오류와 항목 위치를 포함한다 (ADR-0002와 연계).
