# ADR-0002. 사용자 입력 검증은 Collect-All

- **상태**: 확정
- **결정**: 모든 검증 규칙을 실행하고 오류 목록을 한 번에 반환한다. 오류에는 몇 번째 항목인지(itemIndex)를 포함한다.
- **배경**: 오류를 하나씩만 알려주면 고치고 다시 올리는 왕복이 오류 개수만큼 반복된다. 한 신청에 항목이 5~100개라 더 심해진다.
- **대안**: Fail-Fast(첫 오류에서 중단) → 서버는 단순하지만 사용자 경험이 나쁨.
- **예외**: 규칙 간 의존 관계가 있으면(예: 단말 유형이 없으면 호환성 검증 불가) 해당 규칙은 건너뛰고 "선행 오류로 검사하지 않음"을 알린다.
- **결과**: 규칙 간 의존 관계도를 Validation Rule 정의(STEP 10)에서 작성한다.
