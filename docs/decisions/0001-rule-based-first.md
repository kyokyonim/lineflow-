# ADR-0001. AI보다 규칙 기반을 우선한다

- **상태**: 확정
- **결정**: 검증, 비교, 분기 처리는 일반 백엔드 로직으로 구현한다. AI(RAG)는 자연어 문의/매뉴얼 검색에만, 핵심 기능 안정 후 적용한다.
- **배경**: 오류 원인(단말기 번호, 요금제 ID 등)은 필드 비교로 결정적으로 판별된다. 문제는 원인이 모호한 것이 아니라 시스템이 원인을 구분해 알려주지 않는 것이다.
- **대안**: LLM으로 오류 원인 추정 → 정답이 하나로 정해지는 문제에 확률 모델을 쓰면 오히려 위험하고 책임 소재가 불분명해서 기각.
- **판별 기준**: 입력과 정답이 결정적인가? 그렇다면 코드. 표현이 모호하고 문서가 방대한가? 그렇다면 AI 후보.
- **결과**: 소명서 내용 타당성 판단 같은 정책 밖 판단은 AI로도 하지 않는다.
